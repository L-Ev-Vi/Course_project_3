## Учебный проект Course_prodject_3
# *Проект по БД*
*В проекте написана программа, которая получает информацию о вакансиях 10-и кампаний с платформы hh.ru в России.
Спроектированы таблицы в БД PostgreSQL. Программа создаёт БД "companies_and_vacancies" и таблицы с описанием компаний и вакансий. 
Полученная информация сохранятся в созданные таблицы. В программе реализованны методы получения информации 
о компаниях и вакансиях при выполнении SQL запросов к созданной базе данных.*

## Структура проекта
+ main.py — модуль, в котором реализованна функция взаимодействия с пользователем.
+ src/aip_hh.py — модуль, в котором реализован класс для подключения к API HH.ru .
+ src/aip_request_error — модуль, который отвечает за обработку исключений когда код состояния HTTP не равен 200.
+ src/base_parser.py — модуль, в котором описан абстрактный класс для работы с API сервисами.
+ src/creating_database.py — модуль, в котором реализован скрипт для создания базы данных в PostgreSQL.
+ src/base_file_saver.py — модуль, в котором описан базовый класс для подключения к БД "companies_and_vacancies" в PostgreSQL.
+ src/db_manager.py — модуль, в котором реализован класс, для подключения к БД в "companies_and_vacancies" в PostgreSQL, и описаны методы выполняющий SQL запросы.
+ src/drop_database.py — модуль, в котором реализован скрипт для удаления базы данных в PostgreSQL.
+ src/filling_in_tables.py — модуль, в котором описан класс для создания и заполнения таблиц в базы данных "companies_and_vacancies" в PostgreSQL.
+ src/global_variables.py — модуль, в котором хранятся глобальные переменные.
+ src/search_by_hh.py — модуль, который выполняет подключения к API HH.ru для получения списка вакансии.

## Установка
Чтобы работать с проекта необходимо:
1. Загрузить проект в IDE через инструмент *'clone repository'* или команду `git clon`
   используя ключ: 
    - GitHub CLI: `gh repo clone L-Ev-Vi/Course_project_3` для работы из командной строки ОС;
    - или HTTPS: `https://github.com/L-Ev-Vi/Course_project_3.git`;
2. Установить зависимости проекта, выполнив команду `poetry install`;
3. Скачать БД [PostgreSQL](https://www.python.org/downloads/) для вышей ОС;
4. Выполнить установку PostgreSQL:
   - инструкцию по установке на [Windows](https://www.youtube.com/watch?v=TrDBb1zY2SM);
   - [macOS](https://www.youtube.com/watch?v=snLQ6GsxnLk);
   - [Linux](https://www.youtube.com/watch?v=FcTRbMFNdlU);

## Тестирование
Проверка работоспособность программы проводится в пакете `tests`, структуру которой составляют:
- модуль `conftest.py` для хранения фикстур;
-  и тестируемые модуль `test_api_hh.py, test_creating_and_drop_database.py, test_db_companies_and_vacancies.py,
test_db_manager.py, test_search_by_hh.py`


- В модуле задаются параметры для функций, и проводится отработка сценариев поведения программы.
- Для проведения тестов используется фреймворк `pytest`, он устанавливается вместе с зависимостями проекта, но также 
возможно выполнить установку через команду: `poetry add --group dev pytest`
- Запуск тестов производится через команду `pytest` (или конфигурацию используемой IDE)

Для формирования отчёта о том какое количество кода охвачено тестами в процентном соотношении, устанавливается библиотека 
'pytest-cov' через команду: `poetry add --group dev pytest-cov`

Чтобы запустить тесты с оценкой покрытия, можно воспользоваться следующими командами:
+ `pytest --cov` — при активированном виртуальном окружении.
+ `poetry run pytest --cov` — через poetry.
+ `pytest --cov-report term-missing --cov=src` — проверка покрытия тестом с выводом строк
+ `pytest --cov=src --cov-report=html` — чтобы сгенерировать отчет о покрытии в HTML-формате
  - при последнем варианте был сгенерирован отчет `index.html` который храниться в папке `htmlcov`.

## Запуск проекта
При запуске скрипта, программе потребуется некоторое время, что-бы заполнить таблицы компаний и вакансий 
данными с внешнего сервиса HeadHunter.ru!

Запустите модуль main.py через Run :arrow_forward: 
или команду:
    - на Windows через *Terminal:* `python main.py`
    - на iOS через *a-Shell:* `python3 main.py`
    - на Linux через *Linux Terminal:* `python3 main.py`
После чего вам будут доступны все реализованные возможности программы.
